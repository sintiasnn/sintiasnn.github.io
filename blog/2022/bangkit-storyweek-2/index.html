what have I learned during the second week?

During the second week, I continued to study the Basic Learning Web Programming module on the Dicoding web platform. in this module, I learn more about flexbox and basic javascript. At the end of the module, there is a final exam and submission task to find out how well you understand the material being studied and the requirements for getting a certificate.

The submission task in the basic learning module of web programming is to create a simple web with some conditions such as applying HTML semantics, there are all required elements (for example Header, Footer, Main, Article, and Aside), there is an identity for the aside element, and applying float and flexbox.

In this submission, I created a landing page with the title miana world. The reason I created this landing page is that I am interested in miana plants (a type of mint). In practice, this landing page applies basic HTML and basic CSS.

The full details are in my Github repository. you can see it in the link.

After I submitted the results of the landing page that I made, it turned out that my submission was approved by getting a rating of 5. This is because it has met the initial requirements as well as several additional requirements such as colour combinations and others. So that I can pass on this module. Credentials can be seen on the link.

Also in the second week, I studied the Basic Learning Javascript programming module. In this module, I learned many things about javascript such as javascript fundamentals(variable, data type, operator, if/else, loop), data structures(array, object, spread operator, map, set), functions(declaration function, function parameters , arrow function, variable scope, closure), object-oriented programming(class, property & method, 4 pillars of oop, overriding method, object composition), functional programming(functional programming concepts), setup environment(node.js), modules( export-import class), and error handling(try and catch, throwing errors, and custom errors).

On February 24, 2022, ILT-CC-01 or Instructor Lead-Cloud Computing series 1 was held via google meet. This session was attended by groups CC-37, CC-38 and CC-39 guided by Kak Inggih Wicaksono. The material presented is about the basics of HTML and Javascript. The instructor gives a demo program so that it can be understood by students.

In addition, the first weekly consultation session was carried out by the facilitator with CC-38 friends (my group). This session discusses the progress of students during learning and the technical obstacles encountered by students. Because it’s only the first week, we open this session with self-introductions.

I feel happy because I get new insights and can discuss with friends if problems are found while studying. Hopefully, this blog is useful for readers. I apologize if there are mistakes in terms of phrases, grammar, paraphrasing or others. See you in the next blog.
